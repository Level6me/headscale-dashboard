# Headscale 现代化全功能 Web 控制台 (Headscale Dashboard)

专为 Headscale / Tailscale 自建网状网络量身打造的下一代 Web 管理中枢。具备节点全生命周期管理、动态 Mesh 拓扑星图、多节点连通性探测矩阵、零信任 ACL 策略编辑、以及基于飞书 Webhook 的节点掉线秒级自动告警。

---

## 🌟 核心功能一览

### 1. 设备与节点管理 (Nodes)
- **实时状态感知**：动态显示在线/离线呼吸灯、分配虚拟 IPv4/IPv6、公网出口及操作系统。
- **设备运维**：支持一键复制 IP、节点自定义重命名、空间迁移、注销剔除。
- **快捷入网**：支持机器码（`mkey:...`）在线审批登记入网。

### 2. 网络星图拓扑大屏 (Topology)
- **ECharts 力导向动态拓扑**：清晰展现 Headscale 中心控制平面与各节点之间的控制协议链路。
- **Mesh 虚拟互联识别**：直观展示基于 WireGuard 的 P2P 直连与 DERP 中继转发。
- **交互探索**：支持拖拽排布、悬停查看节点网络元数据。

### 3. 多节点探测与延迟矩阵 (Latency Matrix)
- **网状互联测速**：任意两个节点之间的往返时延（RTT）及丢包率矩阵呈现。
- **热力感知**：根据延迟阈值（<30ms 极佳、<80ms 良好、超时不可达）颜色分级。

### 4. 组织空间与用户隔离 (Users / Namespaces)
- **命名空间隔离**：按部门或业务环境（如 dev、staging、prod）划分独立网络空间。
- **一键增删**：在线创建命名空间与统计各空间设备数。

### 5. 预授权接入密钥 (Pre-Auth Keys)
- **免交互加入**：为服务器、无人值守节点或 Docker 容器生成一键入网 Key。
- **安全管控**：支持配置单次/多次复用、临时节点（掉线自动销毁）、过期时间设置。

### 6. 子网路由与出口网关 (Subnet Routes & Exit Nodes)
- **局域网互通**：在线审批各节点宣告的内网网段（如 `192.168.1.0/24`），无需配置静态路由。
- **全局出口**：一键审批激活 `0.0.0.0/0` Exit Node 出口网关。

### 7. 零信任 ACL 访问策略 (Access Control Lists)
- **在线策略编辑**：标准 Tailscale HuJSON 规则高亮编辑。
- **细粒度放行**：支持针对特定用户、IP 范围、协议与端口设置放行规则。

### 8. 飞书运维告警联动 (Feishu Alerting)
- **秒级掉线感知**：后台守护进程持续监控生产节点心跳。
- **富文本卡片推送**：一旦有生产服务器异常断网或离线，自动向飞书群机器人推送告警卡片，恢复后发送上线通知。

### 9. 跨平台极速接入向导 (Quick Connect)
- 一键生成 Linux、macOS、Windows、iOS、Android 客户端的配置命令与连接教程。

## 🚀 快速上手与运行

### 方式 A：直接在宿主机启动（极简便）

```bash
cd headscale-dashboard
./start.sh
```
- 服务将常驻后台运行，并监听 `http://127.0.0.1:8086`。
- 停止服务执行：`./stop.sh`
- 查看实时日志：`tail -f dashboard.log`

### 方式 B：Docker 容器化部署

```bash
cd headscale-dashboard
docker compose up -d --build
```

## ⚙️ 生产环境对接与安全配置

在生产环境中，建议采用最稳妥安全的方式进行对接：

### 1. 生成 Headscale API Key
登录 Headscale 服务端终端，执行：
```bash
# 生成有效期为 90 天的 API Key
headscale apikeys create --expiration 90d
```
终端将输出一串长 token（例如 `hs_key_xxxx...`）。

### 2. 在控制台完成配置
打开本控制台页面 `http://<IP>:8086`，点击右上角【系统设置】：
- **服务地址**：如果控制台与 Headscale 在同一台机器，直接填写 `http://127.0.0.1:8085`（无需放行公网端口，极度安全！）；
- **API Key**：填入上一步生成的密钥；
- **飞书 Webhook**：填入你的飞书群机器人 Webhook 地址；
- 点击【保存配置】并点击【测试与 Headscale 连通性】即可！

### 3. 在 1Panel / OpenResty 中配置反向代理（可选域名访问）
若希望通过公网域名访问控制台（例如 `dash.abab.pw`）：
1. 在 1Panel 网站管理中新建反向代理站点；
2. 代理地址指向 `http://127.0.0.1:8086`；
3. 申请 SSL 证书并开启 HTTPS 即可。
